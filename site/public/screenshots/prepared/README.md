# Cutluma marketing-site screenshot assets

These are non-fabricated crops of the seeded PostPilot demo captures in the parent directory.

- Each original capture was cropped to the same `(x: 230, y: 64, width: 1035, height: 648)` region.
- The crop removes browser/app chrome, debug controls, and the legacy PostPilot sidebar wordmark while retaining real, readable product content.
- Every asset is supplied as an optimised WebP for primary web use and a lossless PNG fallback.
- No UI content, data, labels, or product behaviour was invented or altered.
